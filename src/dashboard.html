How the integration works

🛒 Shopify
A customer order on breadwrightbox.com fires a orders/create webhook.
→
⚙️ Breadwright Bridge (our service · Railway)
The 3PL has no API until 2027 — this service is the interim API. It turns a Shopify order into a Datex-shaped XML file.
1 · VerifyHMAC-signed webhook
2 · Normalizeaddresses, qty, first-order flag
3 · Map SKUsShopify → BW_* codes
4 · Inject packagingbox · insulation · dry ice · inserts
5 · Build XMLCustomer Order Shipment
→
🔒 SFTP
File dropped to the Ice Cube warehouse SFTP /Test folder.
→
🏭 Datex WMS
Warehouse imports the file:
✓ Archive — imported OK
✕ Error — rejected / malformed
↩︎ Return feed (next phase): the WMS drops a ship-confirmation file with the UPS tracking number → our poller writes it back to Shopify and emails the customer. Three flows total: outbound orders, inbound stock (ASN), and return/tracking.
