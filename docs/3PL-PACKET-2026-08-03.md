## 5. Wildgrain daily processing SOP (`Wildgrain Daily Processing.docx`)
The operating model Breadwright will mirror. In Wildgrain's flow: orders export to
XML; the warehouse pulls label PDFs from `https://api.wildgrain.com/icecube/today`
(filename encodes the label count); shortage + material-total reports drive the batch
pick; Datex Rules Engine runs "Soft Allocate" then "Batch Wave" → release → pick.
**Implication:** the warehouse expects to *pull* labels/pack-lists from an endpoint —
possible new scope beyond the XML-over-SFTP bridge (see NEEDS-FROM-BILL.md).
